Glossary

Words you'll meet in the docs, in plain language.

Business words

TenantOne business on StoreEase. "Multi-tenant" = one app serving many businesses.
Owner / staffThe person who signed the business up, and the helpers they invite.
StorefrontThe shop shoppers see at name.storeease.in.
TemplateOne of three complete shop designs (Clean Store, Modern D2C, Dark Futuristic).
PublishMaking a store visible. New stores show "coming soon" until then.
ShopperA person who buys. One StoreEase account (email, name, phone, saved addresses) works at every shop; each shop sees only those who ordered there.
SlugThe web-friendly name in a link, like masala-chai in /products/masala-chai. Made from the product name, never typed.
Add-onAn extra on top of the plan: inventory management, done-for-you setup.
Instant modeHow billing behaves with no Razorpay keys: everything works, nothing is charged.
Auto-pay / mandateThe owner's standing permission (UPI AutoPay or card) for Razorpay to charge monthly.
GraceThe 7 days after a trial ends or a payment stops, before the store is suspended.
SuspendedStore closed to shoppers. The owner can still sign in and pay to reopen it.
MRR / ARRMonthly / annual recurring revenue from paying stores. One-time charges don't count.
ChurnPaying stores (or revenue) lost in a period.
CODCash on delivery: how shoppers pay stores today, along with UPI.
UPI / VPAUPI is India's instant bank-to-bank payment. A VPA (virtual payment address) is the ID you pay to, like priya@okbank. A shop's VPA is set in Store settings and never shown to visitors.
UTR / payment referenceThe number your UPI app shows after a payment. A shopper may enter it when tapping "I've paid"; it is optional.
Payment to confirmA UPI order whose shopper tapped "I've paid" but whose shop hasn't yet tapped "Payment received".
ReturnThe shopper sends the item back and the shop refunds the money.
ReplacementThe shopper sends the item back and the shop sends a new one. Handled inside the request: no new order or payment.
Return windowHow many days after delivery a shopper may ask (set per store for returns and for replacements, 1 to 60, default 7).
Paise1/100 of a rupee. All money is stored as whole paise.
ISTIndia Standard Time. Every report day is an IST day.

Technical words

APIThe backend service the websites talk to, under /api/v1.
RLS (Row-Level Security)A PostgreSQL feature that hides other stores' rows on every query, automatically.
MigrationA versioned change to the database's structure (Alembic).
Host headerThe address the browser asked for. The API picks the store from it.
OTPOne-time password: the 6-digit code shoppers get by email.
JWT / access tokenA short-lived signed pass (15-30 min) that proves who you are.
Refresh tokenA longer-lived secret in a locked cookie, used to get new access tokens.
WebhookA call Razorpay makes to our API when something happens to a payment.
OutboxA queue of emails saved with the order, sent by a background loop.
SweepA background loop that checks every store on a timer (billing, domains).
Monorepo / workspaceOne repository holding several apps and shared packages.
SPASingle-page app: plain files; the browser does the page changes.
Dev gatewayA small local server on port 8080 that routes like CloudFront does.

AWS and hosting words

RegistrarWhere the domain was bought and is renewed: GoDaddy.
DNS / nameserversThe internet's address book, and the servers that answer for our domain (Route 53).
Hosted zoneOur domain's set of DNS records in Route 53.
Wildcard record*.storeease.in: one record that covers every store's address.
A / CNAME / TXT record"Lives at this IP" / "is another name for" / "plain text, used to prove ownership".
ACM certificateFree HTTPS certificate from AWS. Ours covers storeease.in and *.storeease.in.
S3 bucketFile storage. Holds the websites, uploads and backups.
CloudFront / distributionAWS's worldwide cache in front of the sites. A distribution is one CloudFront setup.
OriginWhere CloudFront fetches from: a bucket, or our server (origin.storeease.in).
EC2 / t3.microA rented virtual server; t3.micro is the small 1 GB size we use now.
Elastic IPA fixed public IP address for the server.
ECRAWS's store for Docker images; the backend image lives there.
SSM Parameter StoreWhere settings and secrets live, one parameter per setting.
Session ManagerOpens a shell on the server, or a tunnel to Mailpit/Postgres, without SSH.
Docker / ComposePackages each part (API, Postgres, nginx, Mailpit) as a container; Compose runs them together.
nginxThe web server in front of the API on our server.
Let's Encrypt / certbotFree certificates for the server's own address, renewed automatically.
MailpitA test inbox that catches every email instead of sending it.
Terraform / state / plan / applyInfrastructure as code. State = what it built. Plan = the to-do list. Apply = doing it.
GitHub Actions / workflow / runGitHub's robot, its recipe file, and one execution of it.
OIDCHow GitHub proves its identity to AWS, so no AWS keys are stored in GitHub.
RDS / Elastic BeanstalkAWS's managed database / app hosting. Phase 2.
SESAmazon Simple Email Service: how the app sends its email. Starts in a "sandbox" that mails only verified addresses until AWS grants production access.
DKIMA digital signature added to each email. Receivers check it against a public key published in DNS, so forged mail is spotted.
SPFA DNS list of the servers allowed to send mail for a domain. A domain may have only one.
DMARCA DNS rule telling receivers what to do with mail that fails SPF and DKIM (here: reject), and where to send reports.
MXA DNS record saying which servers receive mail for a domain (here: GoDaddy's, for info@storeease.in).
CSPContent Security Policy: a header telling the browser which addresses a page may load from or send data to.
frame-ancestorsThe part of the CSP that says who may show this page inside a frame. We allow only the page's own address (the dashboard preview).
